🏓 Pickleball Tournament

vdua-ocrolus.github.io/pickle
Round-robin doubles with random partners, then a finals for the top four. 6–24 players.
Internet needed once — to set your phone up beforehand.
No internet needed — for the entire tournament.

1 · Before you leave (needs internet)

  1. Open the link above in Safari or Chrome.
  2. Check the bottom of the screen says “Works offline”. Not there? Refresh once.
  3. Add to your home screen — iPhone: Share → Add to Home Screen. Android: ⋮ → Install app.
  4. Test it: turn on Airplane Mode and open it from the home screen. Opens? You're ready.

2 · At the courts (no internet)

Set up

  1. Tap the tab you're running — Advanced or Intermediate.
  2. Setup → type or paste player names.
  3. Set Courts to how many you actually have.
  4. Tap Generate schedule.

Run it

  1. Schedule lists each round — partners, and who sits out.
  2. Type each score as games finish. To 9, win by 1. Saves instantly.
  3. Standings shows live rankings any time.

Finish it

  1. All games scored → Finals. Top 4 are pre-filled. Tap Start finals.
  2. Three games — everyone partners everyone once — then your two champions.

3 · Let players watch

Data tab → Show standings QR. Hold it up, they scan with their camera and see the standings. They can't change anything. It's a snapshot — show a fresh code each round.

Say this at registration: “Open the link now, while you have signal.” That's all players need to do. Anyone who never opens it and has no signal will just get a blank page when they scan.

Good to know

  • Each phone keeps its own scores. Nothing syncs — whoever scores keeps that phone all day.
  • Don't clear browser data during the event, and don't use Incognito. Both erase scores.
  • A wrong score is rejected. 8–6 turns red — that game can't end 8–6 when you play to 9.
  • Fixing a score: tap it and type over. Standings update instantly.
  • Bring a charger. A dead phone is the only realistic way to lose the scores.

If something goes wrong

Blank page at the courtsYou skipped step 1. Find signal, load once, look for “Works offline”.
Wrong player nameSetup → tap the name to edit, ✕ to remove.
Want new pairingsSetup → Regenerate schedule. Erases scores.
Scores are a messSchedule → Clear all scores keeps pairings.
Want a safety netData → Save. A restore point you can return to.
Practise firstData → Fill random scores, then Kill everything.
